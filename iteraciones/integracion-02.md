# Integración 02 - MVP desplegado y demo

## Objetivo

Llevar la tribu a un MVP integrado y desplegado, con frontend web público, backends accesibles y smoke de demo listo.

## Entrega asociada

- esta iteración prepara la entrega final de la tribu.

## Entregables esperados

- `scripts/smoke-mvp.sh`
- `entregas/integracion-02.md`

## Criterio de cierre

- el frontend y los dos backends están desplegados en URLs públicas;
- el frontend conecta con ambos servicios sin problemas de CORS;
- el smoke test de producción pasa antes de la demo;
- la demo muestra el MVP integrado con una narrativa clara.
