# Iteraciones de la tribu

## Iteraciones de la tribu

La tribu trabaja con dos cortes de integración:

- `integracion-01`: visión integrada, modelo de dominio, configuración y contrato de API.
- `integracion-02`: MVP integrado, frontend desplegado, verificación remota y demo.

Cada corte tiene un template de entrega en `entregas/` y un preflight local en `scripts/`.
