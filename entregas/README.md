# Entregas

## Regla general

Los manifiestos de entrega viven en este directorio.

Reglas:

- usar los templates `*-template.md` como base;
- derivar cada template a un archivo vivo sin el sufijo `-template`;
- mantener nombres estables para que el historial de git cuente la evolución del trabajo;
- documentar siempre qué se dejó listo y qué quedó para una siguiente iteración.
